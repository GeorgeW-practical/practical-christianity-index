# Practical Christianity — Devotional Index

A structured, machine-readable index of the [Practical Christianity](https://practicalchristian.substack.com) devotional archive (George Willeboordse's verse-by-verse Bible studies, published on Substack).

**Why this exists:** Substack gives no control over `robots.txt`, sitemaps, or structured data, and most devotionals are paywalled after a paragraph or two — which makes the archive hard for AI systems (and search engines) to discover and cite accurately. This repo publishes a free, fully public index — title, Scripture passage, and an open one-line summary for every devotional, linking back to the full piece on Substack — so AI tools and search engines have something clean to crawl and cite, while the full studies stay on Substack.

**Live page:** https://georgew-practical.github.io/practical-christianity-index/

## What's in here

- `data/devotionals.csv` — the source catalogue: one row per devotional (title, passage, Substack URL, one-line teaser, date, free/paid). Derived from a Substack "posts export" (Settings → Exports), filtered to published newsletter-type posts.
- `scripts/build.py` — reads the CSV and generates `index.html`, `llms.txt`, `sitemap.xml`, and `robots.txt`.
- `scripts/from_substack_export.py` — converts a raw Substack `posts.csv` export into `data/devotionals.csv`.
- `.github/workflows/build.yml` — GitHub Actions workflow that runs `scripts/build.py` and deploys the result to GitHub Pages automatically on every push to `main`.
- `index.html` — the published index page (human-readable, plus embedded schema.org structured data for AI/search crawlers, and a client-side search box).
- `llms.txt` — a plain-text/Markdown overview of the archive, in the emerging `llms.txt` format some AI tools look for.
- `sitemap.xml`, `robots.txt` — standard crawler discovery files.

Note: `index.html`, `llms.txt`, `sitemap.xml`, and `robots.txt` are build outputs — they're generated by the GitHub Actions workflow, not hand-edited or committed to the repo.

## Current status

Indexes the full published archive: **1,153 newsletter-type posts** pulled from a Substack posts export. Podcast episodes and restacked/cross-posted items were intentionally excluded, since they aren't part of the devotional teaching archive itself.

## Updating

1. Add rows to `data/devotionals.csv` — or regenerate it from a fresh Substack export by running `python3 scripts/from_substack_export.py`.
2. Commit and push to `main`.
3. GitHub Actions automatically rebuilds `index.html`, `llms.txt`, `sitemap.xml`, and `robots.txt`, and redeploys to GitHub Pages. No manual build step needed.

You can also trigger a rebuild manually from the **Actions** tab → "Build and deploy index" → "Run workflow", without changing any data.
